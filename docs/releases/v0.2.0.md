# Desktop Calendar v0.2.0

## 변경 사항

- 절전 복귀 또는 자정 경과 후 `오늘` 강조가 이전 날짜에 남는 문제를 수정했습니다.
- 현재 월을 보고 있을 때 월이 바뀌면 새 현재 월로 자동 전환됩니다.
- 날짜별 날씨 상세 패널에서 마지막 업데이트 시각을 확인할 수 있습니다.
- 날짜별 날씨를 클릭하면 버튼 위치에서 시간대별 날씨·기온·체감온도·강수확률·강수량 패널이 열립니다.
- 상단 도구 모음에 명확한 `⏻ 종료` 버튼을 추가했습니다.
- 일정 시간에 `1400` 또는 `930`처럼 입력해도 `14:00`, `09:30`으로 자동 변환됩니다.
- 일정이 많은 날짜 칸에서 마우스 휠로 전체 일정을 스크롤하고 완료·하이라이트 대상을 선택할 수 있습니다.
- 날짜 셀의 스크롤바를 화살표 없는 얇은 라운드 핸들로 재디자인해 캘린더 테마와 자연스럽게 어울리도록 개선했습니다.
- 설정에서 일정 글꼴 크기를 변경하면 공휴일뿐 아니라 기존에 만든 모든 일정에도 즉시 미리보기되고 일괄 저장됩니다. 이전 버전에서 이미 변경한 크기도 첫 실행 때 자동 복구됩니다.
- 공휴일과 일반 일정을 같은 콘텐츠 행과 공통 스타일로 통합해 시작 높이·항목 높이·글꼴·크기·글자색이 일관되게 표시됩니다.
- 일정 카드의 고정 여백을 줄이고 글꼴 크기에 따라 높이가 자동으로 증감하도록 개선했습니다.

## 다운로드

### Portable — 일반 사용자 추천

`DesktopCalendar-v0.2.0-win-x64-portable.zip`

- 별도의 .NET 설치 없이 실행할 수 있습니다.
- ZIP을 압축 해제한 뒤 `DesktopCalendar.exe`를 실행합니다.

### Slim — 작은 다운로드 용량

`DesktopCalendar-v0.2.0-win-x64-slim.zip`

- .NET 10 Desktop Runtime x64가 필요합니다.
- ZIP 전체를 압축 해제한 뒤 `DesktopCalendar.exe`를 실행합니다.

기존 일정과 설정은 `%LOCALAPPDATA%\DesktopCalendar`에 유지됩니다.
