# Desktop Calendar v0.2.1

## 변경 사항

- 일정에 카테고리별 이모지를 지정하고 캘린더에서 바로 확인할 수 있습니다.
- 일정 기본색과 독립된 5색 하이라이트 팔레트를 추가했습니다.
- 진행 중 하이라이트 일정, 일반 진행 일정, 완료 일정 순으로 정렬합니다.
- 날짜별 상세 날씨에 시간대별 예보와 과거 7일 날씨 데이터를 반영했습니다.

## 다운로드

### Portable — 일반 사용자 추천

`DesktopCalendar-v0.2.1-win-x64-portable.zip`

- 별도의 .NET 설치 없이 실행할 수 있습니다.
- ZIP을 압축 해제한 뒤 `DesktopCalendar.exe`를 실행합니다.

### Slim — 작은 다운로드 용량

`DesktopCalendar-v0.2.1-win-x64-slim.zip`

- .NET 10 Desktop Runtime x64가 필요합니다.
- ZIP 전체를 압축 해제한 뒤 `DesktopCalendar.exe`를 실행합니다.

기존 일정과 설정은 `%LOCALAPPDATA%\DesktopCalendar`에 유지됩니다.
